# SI-Coder v0.9.3

SI-Coder v0.9.3 is a narrow runtime-contract follow-up to the v0.9.2 hardening release. It does not rewrite or retag v0.9.2. The goal is to make the supported Node.js claim exactly match what the repository verifies.

## Tested Node.js majors only

The package and local installer now support Node.js majors **22, 24, and 26** explicitly:

```text
^22.0.0 || ^24.0.0 || ^26.0.0
```

This intentionally excludes Node 23 and 25, which are EOL, instead of using the broader `>=22` range. The v0.9.3 regression suite is verified on:

- Node 22.23.2;
- Node 24.20.0;
- Node 26.8.1.

The installer rejects unsupported majors before linking skills or credentials, and CI continues to use Node 22 as the release gate with Node 24/26 compatibility jobs.

## v0.9.2 hardening remains intact

The previous release already shipped the larger security/UX changes: named-connection-first setup, fail-closed unfinished skills, repository-wide secret scanning, GitHub classic-PAT diagnostics, MCP 2026-07-28 + 2025 compatibility, pinned release Actions, npm provenance fallback, release artifact attestation, and public-reachability gating. v0.9.3 preserves those behaviors and only tightens the runtime/support contract and current documentation/version links.

## Verification

The release remains gated by JS + installer syntax checks, full regression, documentation synchronization, lifecycle catalog validation, deterministic generated artifacts, strict skill verification, repository-wide secret scanning, and the Node 22/24/26 test matrix.
