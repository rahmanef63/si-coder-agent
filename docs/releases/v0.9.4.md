# SI-Coder v0.9.4

SI-Coder v0.9.4 makes skills a portable runtime contract instead of a UI-specific convention. It also ships the frontend quality skills added after v0.9.3 (`sc-ui`, `sc-ux`, `sc-dx`, `sc-ax`, and `sc-fe`).

## Slash skill registry

The installed CLI now exposes the active/default skill catalog directly:

```bash
sc skills
sc skills --json
sc skill list --json
```

The JSON form is intended for MSO, Control Room, Baton, and other surfaces that embed SI-Coder capabilities. Every row includes the canonical skill name, description, filesystem path, lifecycle state, and slash invocation such as `/sc-fe`.

The shared interaction contract is:

- `/skills` — discover available skills in a host UI;
- `/<skill> [prompt]` — invoke one unambiguous skill directly;
- `/skill <exact-id> [prompt]` — explicit ambiguity escape hatch when a host has multiple project/global skills with the same name.

The CLI keeps the existing `sc skill verify` command intact; `sc skill list` is additive.

## Frontend quality skills

The active/default catalog now includes the frontend quality system introduced on main after v0.9.3:

- `sc-ui` — visual interface quality and anti-slop checks;
- `sc-ux` — usability, accessibility, interaction and recovery;
- `sc-dx` — frontend developer experience;
- `sc-ax` — agent ergonomics and recoverability;
- `sc-fe` — orchestration across UI, UX, DX and AX, including presets such as `--apple` and `--workbench`.

## Distribution fix

The npm `sc` binary now enters through a thin slash-aware wrapper and delegates every existing provider, credential, deploy, update, audit and TUI command to the mature `bin/sc.js` implementation. This keeps the existing control plane stable while giving external surfaces a deterministic skill registry.

## Verification

The release remains gated by full repository regression, catalog validation, generated plugin parity, deterministic skill archives, documentation synchronization, secret scanning, and the Node 22/24/26 test matrix.
