# SI-Coder v0.8.1

SI-Coder v0.8.1 makes distribution surface-aware so a non-technical user can install from the GitHub repository or a single skill package without learning the differences between plugin systems.

## Highlights

- Claude Code marketplace/plugin installation from the SI-Coder GitHub repository.
- Self-contained `sc.skill` plus ZIP compatibility artifact for web/import surfaces.
- OpenAI GitHub marketplace at `.agents/plugins/marketplace.json`.
- Separate web-compatible OpenAI skill-only plugin under `plugins/si-coder/`.
- ChatGPT workspace marketplace import and daily-sync support.
- ChatGPT personal Skill upload support.
- Codex GitHub skill-installer path.
- `AI_INSTALL.md` tells an AI agent how to install SI-Coder after being given only the repository URL.
- Secret-safe credential boundary and non-technical `/sc` workflow preserved.

## Assets

- `sc.skill`
- `sc.zip`
- `sc-build.skill`
- `manifest.json`

## Install matrix

| Surface | Install | Invoke |
|---|---|---|
| Claude Code | `/plugin marketplace add rahmanef63/si-coder-agent`, then install SI-Coder | `/sc` |
| Claude Web | Upload packaged skill/ZIP in Customize → Skills | automatic when relevant |
| Codex | install core GitHub skill paths | `$sc` when explicit selection is supported |
| ChatGPT personal Skills | Upload packaged skill in Plugins → Skills | automatic when relevant |
| ChatGPT workspace | Import GitHub marketplace | `@SI-Coder` / `+ → More` when available |

Full installation guides: `https://github.com/rahmanef63/si-coder-agent/blob/main/docs/install/README.md`.
