# SI-Coder v0.8.3

This release makes the installation transport contract explicit per AI surface.

## Canonical format

The Agent Skills standard defines a skill as a directory containing `SKILL.md`. `SKILL.md` is the required entry point; `scripts/`, `references/`, `assets/`, and client metadata can live beside it.

## Install transport by surface

| Surface | Transport |
|---|---|
| Claude Code | GitHub plugin marketplace or skill directory containing `SKILL.md` |
| Claude Web | `sc.zip` |
| Codex | GitHub skill directories containing `SKILL.md` |
| ChatGPT personal Skills | `sc.zip` recommended; OpenAI does not document `.skill` as required |
| ChatGPT workspace | GitHub plugin marketplace |
| Generic Agent Skills | skill directory containing `SKILL.md` |
| Explicit `.skill`-aware clients | optional `sc.skill` archive |
