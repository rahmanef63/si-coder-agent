# SI-Coder v0.8.9

SI-Coder v0.8.9 stabilizes the Finder column layout so entering Providers no longer resizes or scrolls the existing navigation frame.

## Highlights

- Wide terminals reserve four fixed-width Finder column slots from the start.
- Opening Providers fills the reserved fourth slot instead of shrinking the first three columns.
- Paths deeper than four layers slide the oldest column out while preserving exactly four visible columns.
- Medium and narrow terminals use the same stable-slot model with three and two columns.
- `PREVIEW` and `RESULT` now share one fixed-height footer region, so provider navigation does not change body height.
- The renderer no longer emits a trailing newline on the terminal's final row, preventing alternate-screen scroll that could hide the header.
- Added regression coverage for stable separator positions, four-column paging, fixed frame height, and no final-row scroll.
- User ownership, provider state, credential isolation, and the v0.8.8 MSO/MCP tool-calling contract are unchanged.
