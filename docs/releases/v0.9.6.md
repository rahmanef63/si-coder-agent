# SI-Coder v0.9.6

SI-Coder v0.9.6 adds first-class managed skill CRUD and makes the primary README outcome-oriented with concrete use cases and a resource CRUD map.

## Managed skill CRUD

- `sc skills` / `sc skills --json` discovers bundled plus managed project/global skills.
- `sc skill show <name|exact-id> [--raw] [--json]` inspects a skill.
- `sc skill create <name> --description \"...\" [--scope project|global] [--from-file SKILL.md]` creates a managed skill.
- `sc skill update <name|exact-id> [--description \"...\"] [--from-file SKILL.md]` updates a managed skill with validation and rollback.
- `sc skill delete <name|exact-id> --yes` removes a mutable managed skill.

Project skills live in `.mso/skills`; global operator skills live in `~/.mso/skills`. Bundled package skills remain read-only. Project scope wins normal same-name resolution and `/skill <exact-id>` remains the explicit ambiguity escape hatch. Installer symlinks that point back to bundled SI-Coder skills are deduplicated from the registry.

## README / operator UX

The README now starts from real use cases: building a product, improving an existing frontend with `sc-fe`, applying presets such as `--apple` or `--workbench`, connecting providers, deploying/domains, multi-client identities, custom skills, and cross-platform slash invocation. It also includes a CRUD matrix for users, provider definitions, connections, credentials, and skills.
