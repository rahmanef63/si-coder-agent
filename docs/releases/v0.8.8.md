# SI-Coder v0.8.8

SI-Coder v0.8.8 fixes provider/user state confusion in the Finder TUI and makes the user-first credential model available as first-class agent tools.

## Highlights

- Provider/user rows now use a shared secret-safe read model instead of independently deriving status.
- The Finder bottom panel is now a live `PREVIEW` for the highlighted user/provider/credential.
- Action output is shown as a temporary `RESULT` and disappears after navigation, preventing stale provider output from looking current.
- User deletion now requires typing the exact user name in the interactive CLI and records a metadata-only audit event.
- Default/map/unmap/delete user mutations are audit-visible.
- Added explicit user-scoped MSO/MCP tools for user CRUD, routing, provider status/verification, and credential status/request/delete.
- Credential create/rotate tool calls remain intentionally value-free: agents receive a safe hidden-terminal handoff instead of a secret input field.
- `.mso/functions.json` remains the tool schema SSOT and `scripts/sc-mcp.js` exposes the same tools to MCP clients.
- `install.sh --with-mcp` now includes native registration paths for Hermes and OpenClaw in addition to Codex/Claude.
- Added `docs/tool-calling.md` with MSO, Claude Code, Codex, Hermes, OpenClaw, and generic MCP examples.
