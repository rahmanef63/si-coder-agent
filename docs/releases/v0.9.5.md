# SI-Coder v0.9.5

SI-Coder v0.9.5 makes self-update bootstrap-safe for installations whose global `sc` command still points at the pre-0.9.4 `bin/sc.js` entry.

## Update compatibility

- `bin/sc.js` now exposes `sc skills` and `sc skill list` directly, matching `bin/sc-entry.js`.
- A single fast-forward update is enough for old global links to gain the slash registry; users do not need a manual relink first.
- The updated self-updater also runs an idempotent `npm link` repair after an update (or when already current) and reports the link result without weakening fast-forward-only safety.
- `sc skill verify` remains unchanged.

## Shared slash contract

The cross-platform contract remains `/skills`, `/<skill> [prompt]`, and `/skill <exact-id> [prompt]` for MSO, Control Room, Baton, and compatible hosts.
