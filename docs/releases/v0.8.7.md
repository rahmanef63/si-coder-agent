# SI-Coder v0.8.7

SI-Coder v0.8.7 makes credential ownership user-first and adds safe user duplication, rename, legacy import, and per-user credential CRUD.

## Highlights

- Finder hierarchy is now `Users → <user> → Providers → <provider> → Credentials → <KEY>`.
- Removed credential editing from the global provider/catalog surface; a user must be selected first.
- Duplicate a user to copy all provider credentials into an independent store without exposing values.
- Existing empty users can be filled with `--replace-empty`; non-empty destinations are never overwritten.
- Rename a user while migrating default-user and folder-mapping references.
- Import recognized legacy shell credentials into one user without overwriting existing user credentials by default.
- Read/create/update/delete credentials explicitly under one user.
- User-scoped provider verification uses only the selected user's credentials and strips credentials not owned by that user.
- Finder paths always show which user owns the provider/credential being managed.
- Existing profile files remain the backward-compatible storage implementation; the product/UI domain is now user-first.
