## Archive relationship

`sc.zip` and `sc.skill` are sibling release assets with identical bytes. `sc.zip` does **not** contain a nested `.skill` file. Opening either archive reveals the normal `sc/` skill directory with `SKILL.md` and bundled resources.

## Documentation contract

`docs/install/README.md` is the installation-format SSOT. `npm run docs:sync` updates generated copies, while `npm run docs:check` fails on drift. CI runs the checker and validates generated skill artifacts.
