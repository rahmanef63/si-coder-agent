# SI-Coder v0.8.10

SI-Coder v0.8.10 adds source-aware credential guidance so users know exactly where to obtain each API key/token/identifier before hidden input begins.

## Highlights

- Every built-in dashboard-backed credential now carries a reference URL plus `navigation[]` click path in `lib/providers.js`.
- Local/generated values use a safe `createCommand` or explicit generated-at-deploy instructions instead of a fake dashboard URL.
- Finder credential PREVIEW now shows `open:`/`get with:` and `click:` guidance before Set/Rotate is opened.
- Hidden-input CLI repeats the same official URL/command and navigation path before asking for the value.
- `sc.user.credential.request` and legacy secret handoffs return `referenceUrl`, `createCommand`, `navigation`, and `navigationText`.
- `lib/providers.js` + `lib/credential-guidance.js` are the source of truth; onboarding step markdown is extended reference only.
- Added regression coverage requiring every built-in URL-backed credential field to have click-by-click navigation metadata.
