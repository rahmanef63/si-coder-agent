# SI-Coder v0.8.13

## Highlights

- Restores the stable four-column Finder experience for deep provider navigation.
- `Providers` + selected provider remain anchored while connection/credential layers rotate through the two right-hand slots.
- Keeps the familiar v0.8.9 layout at the first provider-entry depth.
- Creates real Convex Cloud connection metadata for an example user: account-level `Convex Admin` plus project-scoped `Example App Dev`.
- Stores the non-secret project deployment identifier while leaving PAT/deploy key entry to the hidden terminal.

## Safety

No plaintext provider secret is added to the repository, logs, MCP JSON, or release artifacts. Live Convex secret fields remain missing until the user enters them locally through SI-Coder hidden input.

## Verification

- deep Finder provider anchoring regression test
- global PTY smoke at Credentials and credential-action depth
- full repository test suite
- deterministic `.skill` / `.zip` build
- install docs SSOT check
