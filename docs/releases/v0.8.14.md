# SI-Coder v0.8.14

SI-Coder v0.8.14 fixes the remaining Finder TUI corruption seen in Windows Terminal/SSH where the whole frame could scroll upward even though the four-column layout itself was correct.

## Highlights

- Finder rows are now painted by absolute terminal cursor coordinates instead of newline-delimited streaming.
- One physical terminal cell is reserved at the right edge so a full-width row cannot trigger implicit auto-wrap.
- The existing four-column provider anchoring, fixed footer, user-first hierarchy, and named connections remain unchanged.
- Added a regression contract requiring one cursor-addressed paint per terminal row, no streamed newlines, and a one-cell safe right margin.
- No user credentials, mappings, defaults, or Convex connection metadata are modified by this patch.
