# SI-Coder v0.9.8

SI-Coder v0.9.8 fixes self-update UX for working checkouts with local source changes.

## Safe dirty-worktree updates

- `sc update` is still Git fast-forward-only.
- Dirty tracked and untracked work is preserved automatically before a required fast-forward.
- Local work is restored after the fast-forward and the temporary stash is dropped only after a successful restore.
- If restoration conflicts with upstream, the updated source stays installed, the stash remains recoverable, and SC reports the recovery reference instead of discarding work.
- Ahead, diverged, and detached checkouts remain blocked.
- Runtime-only `.agent` artifacts still do not count as source dirtiness.

## Why

Provider/skill installation can legitimately add local extensions such as a new provider adapter or skill. Updating SI-Coder should not force a non-technical user to choose between `commit`, `stash`, or losing those changes.
