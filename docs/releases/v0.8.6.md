# SI-Coder v0.8.6

SI-Coder v0.8.6 replaces the line-appending bare-`sc` navigator with a Finder-style alternate-screen terminal UI.

## Highlights

- One stable alternate-screen frame; navigation no longer appends lines to terminal scrollback.
- Visible `SECTIONS` tab bar plus `PATH` breadcrumb tabs.
- Finder-style parent/current columns with persistent selected branches.
- Responsive column count: older parents collapse behind `… /` on narrow terminals.
- `Tab`/`→` enters deeper branches, `Enter` opens/runs, `←`/`Esc` goes back, and `Ctrl-D` exits.
- Non-interactive actions render into a `LAST ACTION` panel in the same frame.
- Interactive credential/profile actions temporarily use the TUI screen and return to Finder without closing `sc`.
- Removed the obsolete line-walking `selectLayer()` engine so bare `sc` has one navigation implementation.
- Existing profile ownership, folder mapping, and secret-isolation behavior is unchanged.
