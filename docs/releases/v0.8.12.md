# SI-Coder v0.8.12

SI-Coder v0.8.12 completes the v0.8.11 multi-connection release by surfacing per-field acquisition guidance while the user/agent is still choosing an authentication method, before a connection is created.

## Highlights

- `sc.user.connection.request` now includes `fieldGuidance` for every auth method field.
- Each field guidance includes the official/reference URL or local command, click-by-click navigation, required state, and notes without any credential value.
- Convex Cloud `personal-access-token` immediately exposes `https://dashboard.convex.dev/profile#personal-access-tokens` plus dashboard navigation.
- Convex Cloud `deployment-key` immediately exposes guidance for both `CONVEX_DEPLOYMENT_NAME` and `CONVEX_DEPLOY_KEY`.
- Finder auth-method selection shows the first required field's endpoint/navigation before the label/input step.
- Existing named connection storage, live migrated credentials, four-column Finder layout, and 32-function secret-safe MCP/MSO contract remain unchanged.
