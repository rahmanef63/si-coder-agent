## CLI navigation

- `Tab` enters a deeper layer.
- `→` or `Enter` opens/runs the selected item.
- `←` or `Esc` goes back one breadcrumb layer.
- Completing an action returns to the current layer instead of closing `sc`.
- `Esc` at Home does not quit; use Quit or Ctrl-D.

Example breadcrumb: `SI-Coder › Users › Profiles › rahmanef`.

## Credential ownership

Each profile can now declare which human/account owns its environment credentials. Credential values remain in the profile `.env` file; owner metadata is stored separately in `~/.config/si-coder/profile-meta.json` with mode 0600 and never duplicates secret values. Legacy profiles default to owner = profile name.

Commands: `sc user show`, `sc user owner`, `sc user map`, and the corresponding interactive Users/Profile layers.
