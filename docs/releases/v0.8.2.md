# SI-Coder v0.8.2

> **Historical release record:** behavior, installation labels, and provider recommendations below reflect this release at the time it shipped. For current guidance, use [`../install/README.md`](../install/README.md).


SI-Coder v0.8.2 corrects cross-platform skill invocation semantics while preserving the one-file `.skill` distribution model.

## What changed

- The canonical skill identity is `sc`, independent of host invocation syntax.
- ChatGPT personal Skill metadata now registers `display_name: sc`.
- ChatGPT personal Skills use automatic selection or explicit `@sc` selection.
- Claude Code continues to expose the same skill as `/sc`.
- Workspace Plugin Marketplace installs continue to expose the plugin as `SI-Coder` / `@SI-Coder` where explicit plugin selection is available.
- `.skill` remains the portable ZIP-format install package, but the docs now explicitly state that packaging a Skill does not register a custom ChatGPT Web `/slash` command.
- Internal routing uses skill identities (`sc-build`, `sc-all`, `sc-provider`, and others) instead of assuming slash syntax.

## ChatGPT personal Skill

After installing the ZIP/`.skill` package, use either:

```text
@sc Build a booking app for my salon.
```

or ask naturally and allow ChatGPT to select the Skill automatically.

`/sc` is not claimed for ChatGPT Web. It remains the Claude Code invocation for the same canonical `sc` skill.
